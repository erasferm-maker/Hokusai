# Hokusai Exhibition

Landing page for the Hokusai art exhibition, built from the Figma design in three versions:

- **Desktop** (1280 px and up)
- **Tablet** (768–1279 px)
- **Mobile** (up to 767 px)

Pure HTML, CSS and JavaScript, no build step. Open `index.html` in a browser, or publish the folder with GitHub Pages.

## Structure

- `index.html` — the page markup
- `css/style.css` — all styles (desktop, tablet and mobile)
- `js/main.js` — scaling, spacing, menu and text animations
- `assets/` — images and icons
